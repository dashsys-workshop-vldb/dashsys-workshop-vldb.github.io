## 8. **Visual Word Cloud Recommendations**

### Recommended Designs:

**1. Circular Layout - "Ecosystem View"**
- Center: DATA
- Inner circle: AGENTS, PROVENANCE, SYSTEM
- Outer circle: HUMAN, EVALUATION, FRAMEWORK
- **Shows:** Core infrastructure → implementation → interfaces

**2. Split View - "Duality"**
- Left half: Data management terms (blue)
- Right half: Agentic system terms (purple)
- Overlap in middle: PROVENANCE, FRAMEWORK
- **Shows:** Two-way relationship between themes

**3. Clustered Layout - "Research Areas"**
- 4 distinct clusters matching 4 themes
- Different colors for each
- Size by paper count in that cluster
- **Shows:** Theme distribution

**4. Timeline/Flow Layout**
- Left: Infrastructure (GitLake, State Management)
- Middle: Agent Design (ASMR, GUIDE)
- Right: Human Interface (AgentTrails, Be Fair!)
- **Shows:** System stack from data → agent → human

**5. Network Layout - "Connections"**
- Nodes = key terms
- Edges = co-occurrence in same paper
- Thicker edges = more co-occurrence
- **Shows:** Which concepts cluster together

## 9. **Actionable Insights from Word Patterns**

### What the word clouds tell us:

**1. "Data" is 3x more frequent than "Agent"**
→ Workshop is data-centric, not AI-centric

**2. "Provenance" appears in 6 papers**
→ Emerging infrastructure primitive (as we identified)

**3. "Evaluation" appears only 3 times**
→ Confirms the evaluation gap

**4. "Multi" + "Agent" appear together 4 times**
→ Architectural consensus forming

**5. "Human/Users/Workers" = 8 mentions**
→ HITL is not just a theme, it's embedded in language

**6. "System/Systems" appears 7 times**
→ Focus on building, not just algorithms
